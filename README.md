# ระบบบริหารจัดการร้านสุกี้

โครงการระบบบริหารจัดการร้านสุกี้ มีแนวคิดเพื่อช่วยให้ร้านจัดการงานประจำวันได้สะดวกขึ้น ตั้งแต่การดูแลเมนูและวัตถุดิบ ไปจนถึงการบันทึกยอดขายและตรวจสอบผลการดำเนินงาน

> ปัจจุบันโครงการอยู่ในช่วงเริ่มต้น และหน้าเว็บยังเป็นตัวอย่าง HTML เบื้องต้น

## เป้าหมายของระบบ

- รวมข้อมูลงานสำคัญของร้านไว้ในที่เดียว
- ลดความผิดพลาดจากการบันทึกข้อมูลด้วยมือ
- ช่วยให้ตรวจสอบยอดขายและวัตถุดิบได้ง่ายขึ้น
- สนับสนุนการวางแผนและการตัดสินใจของผู้ดูแลร้าน

## ฟังก์ชันที่วางแผนไว้

- **จัดการเมนู** — เพิ่ม แก้ไข และจัดหมวดหมู่รายการอาหารและเครื่องดื่ม
- **จัดการคำสั่งซื้อ** — บันทึกรายการอาหารและติดตามสถานะคำสั่งซื้อ
- **จัดการโต๊ะ** — ตรวจสอบสถานะโต๊ะและเชื่อมโยงโต๊ะกับคำสั่งซื้อ
- **จัดการวัตถุดิบ** — บันทึกปริมาณคงเหลือและแจ้งเตือนเมื่อวัตถุดิบใกล้หมด
- **จัดการยอดขาย** — สรุปยอดขายและรายการชำระเงินตามช่วงเวลา
- **จัดการพนักงาน** — กำหนดข้อมูลและสิทธิ์การใช้งานตามหน้าที่

## ผู้ใช้งานที่คาดหวัง

- **ผู้ดูแลระบบหรือเจ้าของร้าน** — ตั้งค่าระบบ จัดการข้อมูล และดูรายงาน
- **พนักงานรับรายการ** — จัดการโต๊ะและบันทึกคำสั่งซื้อ
- **พนักงานครัว** — ตรวจสอบรายการอาหารที่ต้องจัดเตรียม
- **พนักงานแคชเชียร์** — ตรวจสอบคำสั่งซื้อและบันทึกการชำระเงิน

## เทคโนโลยี

หน้าเว็บตัวอย่างในระยะเริ่มต้นสร้างด้วย HTML โดยสามารถต่อยอดด้วย CSS และ JavaScript รวมถึงเชื่อมต่อระบบจัดเก็บข้อมูลเมื่อพัฒนาฟังก์ชันเพิ่มเติม

## การเริ่มต้นใช้งาน

เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์เพื่อดูหน้าเว็บตัวอย่าง

## การพัฒนาต่อ

ฟังก์ชันที่ระบุไว้เป็นแนวทางสำหรับการพัฒนาในอนาคต รายละเอียดการทำงานจริงอาจปรับเปลี่ยนให้เหมาะกับขั้นตอนและความต้องการของร้าน
